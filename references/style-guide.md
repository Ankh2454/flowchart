# 剪纸风格规范

## 视觉签名

辨识度来自“节点是物件 + 薄纸叠层 + 小型机械动作”的组合。
只换颜色、加纸纹或给卡片加阴影，都没有完成这种风格。

## 经典基准参数

以下是原有示例与 PNG 素材的经典色板。新图的精修色板、图标与阴影值见
[配色与图标精修](color-icons.md)；两者保持同一剪纸构造，选定后整图一致。

以下数值对应约 1440px 宽画布；整体缩放时同步缩放。

| 角色 | 基准 | 用法 |
| --- | --- | --- |
| 纸底 | #EDF0E8 | 冷调、低对比，不抢物件 |
| 纸片 | #FFFDF4 | 文件与负空间 |
| 深青 | #203E43 | 正文、结构和少量剪影 |
| 橘红 | #E95B38 | 主流向与动作部件 |
| 青绿 | #639E95 | 次流向与辅助部件 |
| 芥黄 | #EFC64A | 夹条、压台、完成标记 |
| 辅助文字 | #586E6C | 说明，不直接用浅青绿写小字 |
| 回流 | #889B91 | 修改、重试，配文字条件 |
| 标题 / 节点 / 说明 | 40–48 / 22–26 / 15–17px | 同一层级统一字号 |
| 主线 / 次线 | 8–10 / 4–6px | 不用厚度暗示不存在的关系 |
| 纸层偏移 | 3–8px | 2–4 层，一层一种作用 |
| 接触阴影 | dx=2 dy=4 blur=1.2 opacity=.18 | 全图同方向，限制到纸层 |
| 内部倾斜 | 0–3°，极少超过 5° | 标题和节点标签保持水平 |
| 纸纹 | opacity=.02–.04 | 固定 seed、静态，低对比；小图可省略 |

色彩服务语义；不能暗示用户未提供的成功、错误或优先级。橘红可作主线，并不自动表示错误。
主/次支线颜色与图例、载荷保持一致，同时保留文字与箭头，避免仅靠颜色理解。
品牌色可以替换同角色颜色，但同时检查正文和背景对比度。

## 物件内部纸层的四种用途

这里的纸层是材质构造，不是架构的语义分层；分区数量按内容决定。

1. **背衬**：偏移一张纸，建立实体厚度或一叠的语义。
2. **主体**：最大、完整的剪影，缩小后仍可辨认。
3. **功能部件**：印章压头、机器滚轴、放大镜、纸偶手臂，用来解释动作。
4. **局部贴片**：胶带、折角、封签，帮助阅读物件；不能每个节点都贴相同装饰。

大部分边缘保持平直或规则弧线。用一两个不对称切角提示手工，不加高频抖动。
折角使用相邻的两块纯色，禁用金属高光、镜面反射或大面积渐变。
只有纸层之间需要阴影；正文、所有细线、整张画布都不应统一投影。
阴影太宽或太深会变成悬浮卡片，改短距离、低模糊、少层数。

## 文字与构图

中文默认系统黑体，避免手写体。英文眉题可用 Avenir Next / Arial，代码才用等宽体。
不要打包商业系统字体；确需跨机器固定字形时，使用许可明确的字体并附许可。
系统字体会产生平台差异，最终 PNG/GIF 固定当前渲染结果。

先为节点短标签和一行说明预留空间，再画物件。超过约两行的说明移到图外正文。
长技术名称可以分行，但保持术语完整，不为“好看”删掉准确含义。
利用分支间的留白安放条件；不添加无意义的序号、星星或英语口号来填空。
分区用浅色大片剪纸或纸签，节点无需再套卡。复杂系统减少装饰，而非缩小所有文字。

### 分区的视觉层级

分区标题比节点标签更醒目、低于整图标题，同一级分区使用一致位置与字号。
用平直切边、少量切角和克制的边界表现大片剪纸底板；底板保持安静，避免厚重投影抢过节点。
相邻分区可采用同色板内可辨别的浅青、浅米或淡陶土底色，节点仍沿用统一的功能配色。
分区底色表达归属，连线色表达流向或关系，两者分工独立；不要每换一个区就把全部图标染成另一种颜色。
即使去掉底色，也应能从标题、边界和间距识别分组，不能仅靠颜色区分。

序号只在需要引导阅读次序或真实阶段顺序时使用，不能暗示不存在的执行顺序。
无需给每个节点都编号；真实层级由“标题 + 底板包含关系 + 跨区连线”共同表达。

## 精修的判断顺序

先看语义，再看剪影，然后看纸层，最后看细节。
缩到 50% 看不到节点区别：先改轮廓；阴影一关就认不出物件：先改结构。
整图看起来像 UI：去掉重复的单节点外卡，用物件主体承载节点；保留有名称、承载多个节点的语义分区。
看起来像通用扁平图标：补上有作用的背衬、折叠或压叠关系，不加随机小图案。
所有物件争抢注意力：减掉局部贴片与多余动作，保留关键节点最鲜明的轮廓。
