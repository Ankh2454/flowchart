# 配色与图标精修

先看 `examples/color-icon-comparison.html`：同样的 8 个概念依次比较原版、只换色、换色并改造型。
新图优先用 `assets/paper-refined.css` 与 `assets/refined-objects.svg`；经典版 paper.css / objects.svg
和原有 PNG 库继续可用。两套 SVG 的 8 类概念相同，选一套内联，不把同名 symbol 同时放进 defs。
这是一套剪纸语言的精修，不要求所有主题都更淡，也不把某种色板视为客观更高级。

## 颜色分工比颜色数量更重要

| 角色 | 精修基准 | 画面任务 |
| --- | --- | --- |
| 纸底 / 纸白 | #F6F3EB / #FFFCF5 | 大面积留白与物件内部 |
| 文字深青 | #243F3C | 文字、小结构；避免给每个物件加整块深色背板 |
| 主体青绿 / 深一档 | #5B8F85 / #39766D | 构造主体、层间分隔 |
| 陶土橘 | #C76749 | 主流向或关键功能部件 |
| 麦穗黄 | #D7B66C | 少量辅助部件，不必每个节点都有 |
| 浅背衬 / 折角 | #D9E3D9 / #E9E1D0 | 用明度差形成纸层，保持边缘可见 |
| 说明 / 回流 | #5C7169 / #80938A | 说明文字 / 带箭头和条件文字的反馈线 |

- 一个物件通常由纸白、一个主体色和一个局部强调色组成。不要把全图色板平均分配给每个图标。
- 同类节点保持相同角色映射；强调色的使用面积随信息重要性变化，不靠无语义的彩虹分区。
- 低饱和是本套基准，不是降低对比度。正文和小标签以约 4.5:1 为目标，必须辨认的图形边界
  和箭头以约 3:1 为目标；浅背衬不能承担唯一的方向/状态信息。
- 小幅阴影只表现接触。精修值 dx=1.5、dy=3、blur=1、opacity=.12；浅色背景下先保证色块
  边缘能辨认，再考虑投影，不能靠加深阴影救轮廓。
- 使用品牌色时按角色换色，同时检查原图、50% 缩图与灰度层次。黄颜色不自动代表警告。

## 让图标成为同一套物件

- 先确定概念的识别特征：队列是顺序票据，存储是层叠介质，处理器有工作腔，完成是确认记号。
  物件外形必须不同；不要用同一种文件夹加不同徽章表达所有节点。
- 统一正面视角、纸层厚度、折角方向与阴影。不同类别可以有不同轮廓，不强求外接框面积相同。
- 在 160px 基准下，细节线约 2.5–4px；内容短线、按钮等只保留支持识别的部分。
  先在 80px 看轮廓，再在 160px 看内部，512px 只用于检查边缘。
- 光学尺寸按有色轮廓校准。圆柱、窄纸张、小人需要分别调整留白，不把透明 PNG 外框当作主体。
- 文档可以带折角，队列可以有叠放；装饰来自构造。大黑背板、统一圆角外卡和每个节点重复的
  亮黄贴条会抹平差异，应在并排看整套物件时决定是否删掉。
- 主角节点可比支持节点大约 1.15–1.3 倍，用于解释视觉重点；并列对比或同级节点保持等权。
  不把大小解释成未经提供的容量、性能或权限。

## 可编辑性与生图素材

精修 SVG 用 `--pc-*` 继承变量，单独打开有 fallback 颜色。图内用 `<use>` 时可在实例上改角色色；
需要部件动画时展开 symbol，并保留 `.pc-piston`、`.pc-front-ticket`、`.pc-top-layer`。
复制必要 defs 时保留 `pc-shadow`，不能与经典版同名定义重复。

已有 16 张 PNG 是经典色板，不能通过 CSS 变量真正重绘内部颜色。不要用整图 hue-rotate
把纸白和阴影一起染色。精修图优先选可编辑 SVG；确实需要新概念时，以同一套参考物件生成
或绘制，统一色板、视角与阴影后再混用。生成图无文字，标签独立排版。

扩充素材先做文档、机器/存储、人物三种差异较大的样本，在目标尺寸并排审查，再扩展整套。
提示词写清主体色、强调色的位置与面积、薄背衬、无外卡；不要只写“高级、精致”。
不根据模型名称或步数认定素材质量，最终以轮廓、识别性、统一性和小尺寸可读性判断。

## 整图验收

先比较颜色分工、轮廓与视觉重量，再比较细节数量。分别看同尺寸的经典图和精修图，记录具体
改进及退步；“更浅”“更复杂”都不是单独的通过理由。复杂图保留关键术语和真实关系，按流程
或系统边界分组，给跨区连线留走廊；不要用缩字和堆图标压缩信息。

用实际完整流程检查，而不只看图标墙：主线是否容易追踪，支持节点是否抢眼，整体是否还有
纸层感。最终 GIF 仍按 SKILL.md 检查三帧与循环接缝；风格优劣需同主题对照或用户反馈，
不能用结构校验通过来宣称超过另一种美术风格。
